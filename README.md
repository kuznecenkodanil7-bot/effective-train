# ReportSystem 1.21.11

Серверный Paper-плагин для жалоб игроков.

## Команды

- `/report <ник> <причина>` — отправить жалобу.
- `/ot` — открыть GUI-меню жалоб для персонала.

## Права

- `reports.use` — разрешает отправлять жалобы. По умолчанию доступно всем.
- `reports.staff` — разрешает открыть `/ot`, смотреть и закрывать жалобы. По умолчанию доступно OP.

## Что есть в меню

- Список открытых жалоб.
- Страницы, если жалоб много.
- ЛКМ по жалобе — открыть подробности.
- ПКМ по жалобе — быстро закрыть.
- Внутри жалобы можно телепортироваться к игроку, если он онлайн.
- Закрытая жалоба сохраняется в `plugins/ReportSystem/reports.yml`, но исчезает из меню открытых жалоб.

## Сборка

Нужен Java 21 и Gradle.

```bash
gradle build
```

Готовый файл будет тут:

```text
build/libs/ReportSystem-1.0.0.jar
```

Скопируй `.jar` в папку `plugins` сервера Paper 1.21.11 и перезапусти сервер.
